# WorkNest 🏢

> SaaS-style Workforce Management Platform

## Tech Stack

- Java 17 + Spring Boot 3.5.14
- MongoDB Atlas
- JWT Authentication
- React + Tailwind (coming Phase 5)

## Setup

1. Clone the repo
2. Copy `application-example.properties` → rename to `application.properties`
3. Fill in your MongoDB URI and JWT secret
4. Run `./mvnw spring-boot:run`
